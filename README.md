# 라이믹스 스티커 모듈

라이믹스 환경에서 디시인사이드나 마루마루와 같이 댓글단에서 이모티콘을 손쉽게 사용하게 해주는 모듈입니다.

## Server Requirements
* PHP version 7.4.0 or greater
* GD Library
* Rhymix latest version (2.1~)

## Installation
[라이믹스 자료실](https://rhymix.org/pds/1953667)에 업로드되어있습니다.  
쉬운설치를 통하여 설치하실 수 있습니다.

## Installation (Manual)
1. zip 파일 다운로드
2. /modules/sticker에 모듈 파일 복사
3. /index.php?module=admin 에서 모듈 설치 후 //your-domain.com/sticker 이동 후 정상동작 확인
